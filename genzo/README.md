# Genzo Content Studio

Sanity Studio for the Genzo jewellery and accessories catalogue.

## Product catalogue

The `product` document schema includes the name and slug, product code, one of the storefront's categories, image gallery, description, material, optional weight, PKR pricing, stock status, and featured/new-arrival flags. A product can either have a regular price (and optional lower sale price) or be marked as price on request.

Run `npm run dev` from this directory to open the Studio locally.
